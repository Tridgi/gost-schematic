# TL494CN — цифровая реконструкция исходной схемы (DRAFT)

Ветка: `reference/tl494-photo-reconstruction-20261114`. Отдельный эксперимент, без изменения `main` и `integration/stage0-12`.

**Цель:** восстановить фотографию принципиальной схемы с TL494CN, IRFZ44N и 1N5822, учитывая физические выводы, номиналы, цепи и разницу между точками соединения и пересечениями без контакта.

## Данные
- 23 позиции компонентов, включая все C1–C7, R1–R8, L1–L2, DA1, VT1, VD1, FU1, X1, X2.
- 16 физических выводов TL494CN. `VCC=12`, `GND=7`, `REF=14`, `OUTPUT CTRL=13`, `E1=9`, `E2=10`.
- Предполагаемая топология — инвертирующий преобразователь Ćuk, судя по двум последовательным индукторам и разделительным C1/C2; выход из перечня элементов **−12 В**.
- Вектора и Netlist — **экспериментальные**, НЕ подтверждённые полноценным ERC и не утверждённые по ЕСКД.
- Для визуальных графических файлов применяется вспомогательный генератор (не следует выдавать его за встроенный SVG-рендерер GOST Schematic Engine). Полный нативный ввод TL494 с проверенным каталогом ещё требуется разработать.

## Файлы
- `TL494_E3_clean.svg` — экспериментальная чистая схема.
- `TL494_E3_diagnostic.svg` — выводы и контрольные метки.
- `TL494_netlist.json` — список физических связей.
- `TL494_elements.csv` — перечень элементов.
- `TL494_verification.md` — открытые электрические и нормативные вопросы.

Ключевая причина статуса DRAFT: оригинал имеет малое разрешение. Назначения выводов проверены по технической документации, но правильность электрической схемы как работающего устройства **не доказана**.

Технические источники: [Texas Instruments TL494](https://www.ti.com/product/TL494), [Infineon IRFZ44N](https://www.infineon.com/part/IRFZ44N), [Vishay 1N5822](https://media.digikey.com/pdf/Data%20Sheets/Vishay%20Semiconductors/1N5820-5822.pdf).
