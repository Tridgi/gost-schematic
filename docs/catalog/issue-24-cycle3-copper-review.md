# Issue #24 — исправление Cu и достоверность происхождения катушек

**Дата:** 2026-11-12; **ветка:** `parallel/catalog-cycle3` (создана от `integration/stage0-12` @ `840576d31ac7ff201fe64144c273e3aefbb1ab83`). Все **19 УГО DRAFT**, внешнее нормативное одобрение **BLOCKED**.

## 1. Исходные нормы и классификация

| УГО | Первичный источник | Вывод |
|---|---|---|
| `inductor.trim_copper` | [ГОСТ 2.723-68, п.5 табл.1 поз.2а, прим.1, PDF стр.2](https://helpeng.ru/public/normdoc/eskd/gost_2.723-68.pdf#page=2); [п.6 табл.2 поз.7, стр.3](https://helpeng.ru/public/normdoc/eskd/gost_2.723-68.pdf#page=3) | **Немагнитный медный магнитопровод — сплошной**, с химическим символом `Cu`; квалифицирующая отметка подстройки требует отдельной визуальной проверки |
| `inductor.magnetodielectric` и `inductor.trim_magnetodielectric` | ГОСТ 2.723-68, п.5 табл.1 поз.2в; табл.2 поз.5–6 | Магнитодиэлектрический сердечник — **отдельные штрихи**. Размер штриха 2 мм/промежутка 1,1 мм — *проектный* |
| `inductor.double_tapped` | ГОСТ 2.723-68 табл.2 поз.3, форма II, PDF стр.3 | Рисунки одиночного отвода разделены «или»; проектные **два одновременно выведенных отвода** — `editorial_adaptation` |
| `inductor.sliding_contact` | ГОСТ 2.723-68 табл.2 поз.4, форма II, PDF стр.3 | Иллюстрация «например, двумя»; **один** скользящий контакт — `editorial_adaptation` |

Нормативный материал предварительно передан в [Issue #18](../standards/issue-18-high-risk-inductors.md) и [карточках источников](../standards/issue-18-rule-cards.json). Их содержание не менялось. Нормативный пример определяет **тип/семантику**, а не доказывает миллиметровую точность рисунка проекта.

## 2. Техническое изменение

**Только в каталоге:**
- `CoreKind.NONMAGNETIC_COPPER` генерирует `StyledLine(..., dash_pattern_um=())`: **сплошной видимый штрих**. Требуемая аннотация `core_material="Cu"` сохранена.
- `CoreKind.MAGNETODIELECTRIC` продолжает генерировать `StyledLine(..., dash_pattern_um=(2000, 1100))`.
- `inductor.double_tapped.json` и `inductor.sliding_contact.json` имеют `normative_relation=editorial_adaptation` и уточнённый `normative_basis`. Геометрия и физические контакты не менялись.

**Не менялось:** исходный `Line/Semicircle` обмотки, контакты `1`/ `2`/отводы, координаты внешних выводов, `PhysicalPin.function`, `conductor_topology` с явными соединениями, `body_keepout`, `AnnotationSlot`, номиналы и общий движок схем.

**Важно:** сплошная **графическая** линия Cu НЕ означает проводник электрической сети. Сердечник и диагональный маркер подстройки исключены из `conductor_indices`. Добавление сердечника в электрический граф проверяется отрицательным тестом как висящая проводящая группа.

## 3. Воспроизводимое сравнение Cu / магнитодиэлектрика

```sh
python examples/review_copper_core_cycle3.py \
  --output-dir output/copper-core-cycle3
```

Штатный `render_sheet_svg` с построенными через `build_inductor` катушками создаёт **шесть SVG**:

| Группа | Чистый | Диагностический |
|---|---|---|
| Cu | `copper-clean.svg` | `copper-diagnostic.svg` |
| Магнитодиэлектрик | `magnetodielectric-clean.svg` | `magnetodielectric-diagnostic.svg` |
| Совместное расположение для визуального сравнения | `side-by-side-clean.svg` | `side-by-side-diagnostic.svg` |

Также формируется `manifest.json` с источниками, типами штрихов, физическими контактами, проверенными островами и статусом. В SVG действительно присутствует надпись `Cu` из постоянной аннотации, а у магнитодиэлектрика присутствует SVG `stroke-dasharray="2,1.1"`. Диагностическая версия добавляет охранные прямоугольники и контакты без изменения графических или электрических данных.

**Ограничение текста:** для полностью воспроизводимых независимых тестов используется `IllustrativeMetrics` (приближённая геометрия текста), а не измеренный ГОСТ Type A. **Эти SVG — техническая проверка формы, не эталон шрифта**. Для приёмки по ЕСКД необходимо пересоздать изображения с реально установленным и измеренным шрифтом и совместить с оригиналом/КОМПАС, проверить толщину, засечку и место `Cu`.

## 4. Проверки и намеренно неподтверждённое

`tests/test_catalog_cycle3_inductors.py` проверяет:
- Cu↔магнитодиэлектрик (пунктир запрещён для Cu и обязателен для magnetodielectric);
- необходимую отдельную аннотацию `Cu` и её `required`;
- исключение любого сердечника из проводящего графа;
- сохранение четырёх/трёх физических контактов, их `TerminalFunction`, координат и 8 трансформаций;
- отсутствие ложного присвоения `table_2_example` двум адаптациям.

`tests/test_catalog_cycle3_preview.py` контролирует наличие `Cu` в настоящем renderer SVG, стилевые атрибуты линий и воспроизводимость всех шести файлов.

**Не исправлено в Issue #24:** универсальная стрелка подстройки может не совпадать с T-образным ограничителем из ГОСТ 2.721-74; `inductor.variable` остаётся неподтверждённой композицией. Не менять эти формы без отдельного нормативного решения. **Ни один УГО не переводится в APPROVED**.
