# R6 preparation: categorized native catalog

The previously verified baseline 62d0297 has 109 DRAFT UGO, 2728 passing tests on Python 3.12/3.13 (8 skips), 366 focused checks and successful native SVG/PNG export. This patch adds a generator for three geometrically aligned categorized views: clean, diagnostic, protection-only. It uses actual render_symbol_svg output, not redrawn examples. Categories are actual identifier prefixes; labels are display-only Russian headings where mapped. Protection-only retains only native orange body, blue authored routing boxes and green pin markers, plus identifying text. It deliberately does not invent blue zones for old UGO. Every category is paginated in identical layout across views; a JSON manifest enumerates all identifiers and files. GitHub Actions rasterizes all views and uploads the original SVG/PNG. Tests compare exact native subtrees and ensure complete inventory, no functional graphic in protection-only. This is not visual approval; note text extents are conservative estimates and output should be inspected. The eight historical user images are not archived by this patch, and a one-to-one source comparison remains pending. GUI integration and all normative approvals remain pending.
