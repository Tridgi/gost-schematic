# R3 — autotransformers and instrument transformers (DRAFT)

Source: [ГОСТ 2.723-68, table 2, scan p. 9](https://rosgosts.ru/file/gost/01/080/gost_2.723-68.pdf#page=9) for 25,25a; [scan p. 10](https://rosgosts.ru/file/gost/01/080/gost_2.723-68.pdf#page=10) for 30–32. Form II. Six distinct catalog templates, not duplicate rotations. Fixed and regulated single-phase autotransformers have four external pins with a common electrically continuous winding and one tap. Regulating arrow has no conductive role; this is a schematic profile, not a movable-contact simulation. Current transformers have a separate primary conducting bar and one/two secondary groups; no authored junction at the shared graphic axis. Hollow marks at the primary bar ends are permitted by the standard, inset by a project clearance extension from the actual CAD pins. Single CT has no separately drawn core; dual CT profiles distinguish one versus two core strokes. Voltage-measurement template is an application of the generic two-winding profile (TV), not a separately verified GOST shape. All dimensions and abstract terminals are DRAFT; no ratio/rating/simulation. The 35a source reference in R2 double-tapped generic transformer should be treated as a tap-geometry analogy, not a certified generic transformer. Autotransformer tertiary winding, screen, zero sequence and cascading deferred. Full CI/native rendering required.
