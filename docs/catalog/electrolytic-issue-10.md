# Каталог УГО — электролитический поляризованный конденсатор (Issue #10)

**Состояние:** экспериментальный `DRAFT`, revision 1. **Не является проверенным ГОСТ-символом.** Реализовано в самостоятельных файлах
`catalog/symbols/capacitors/electrolytic.json` и
`catalog/parts/capacitors/electrolytic.json`. Существующий `capacitor.polarized`
не меняется и остаётся **обычным поляризованным конденсатором**.

## Нормативный первоисточник

- [ГОСТ 2.728-74, п. 5, таблица 4, позиция 2а, PDF стр. 7](https://helpeng.ru/public/normdoc/eskd/gost_2.728-74.pdf#page=7): электролитический поляризованный — **отдельное изображение** обкладок со знаком плюс.
- [ГОСТ 2.728-74, п. 7, таблица 6, позиция 10, PDF стр. 10](https://helpeng.ru/public/normdoc/eskd/gost_2.728-74.pdf#page=10): отдельный размерный рисунок; на двух узких обкладках проставлено **два размера 1,5 мм**.
- [Официальная карточка Росстандарта](https://protect.gost.ru/gost/details/ba115ccd-e5aa-4ba1-a672-b17170f1a7f2).
- [Нормативный пакет Issue #11](../standards/issue-11-electrolytic.md) отдельно предостерегает от механического переноса **8 мм / 1,5 мм** обычного конденсатора (табл.6 поз.9) на новую геометрию (поз.10).

Контуры двух обкладок воспроизведены четырьмя настоящими `Line`
для каждой, **без закрашивания** и без имитации заливки множеством штрихов.
Используются только штатные примитивы. Внешнее утверждение и точное
1:1 сравнение SVG с контролируемым КОМПАС-эталоном ещё не выполнены.

## Принятый редакционный профиль (координаты в миллиметрах)

Система координат движка: `x` вправо, `y` вниз, локальная ось схемы `y=0`.

| Свойство | Значение | Категория |
|---|---|---|
| Положительная обкладка | `x = -2.25 … -0.75`, `y = -4 … +4` | ширина **1,5** — *трактовка размерной отметки из табл. 6 поз.10*; высота **8** — `EDITORIAL_ASSUMPTION` |
| Отрицательная обкладка | `x = +0.75 … +2.25`, `y = -4 … +4` | ширина **1,5** — *трактовка размерной отметки*; высота **8** — `EDITORIAL_ASSUMPTION` |
| Зазор между внутренними гранями | `1,5` | `EDITORIAL_ASSUMPTION`, НЕ наследовать нормативность обычного конденсатора |
| Положительный вывод | `(-9,0) → (-2.25,0)` | `EDITORIAL_ASSUMPTION`: длина выводов и номеровка |
| Отрицательный вывод | `(+2.25,0) → (+9,0)` | `EDITORIAL_ASSUMPTION`: длина выводов и номеровка |
| Знак плюс | центр `(-3.5,-4.5)`, линейный `+` размером `1,0 × 1,0` | `EDITORIAL_ASSUMPTION`, знаку разрешено не отрисовываться только при гарантии однозначности; здесь знак присутствует |
| Ширина линии | `0,3` | `EDITORIAL_ASSUMPTION`: профиль чертежа, норматив п.7 требует согласованности с линиями связи |
| `body_keepout` | `[-4.5,-5.5,+4.5,+4.5]` | `EDITORIAL_ASSUMPTION`, не чертёжный размер |
| Позиционные обозначения и номиналы | `refdes` над и `value` под УГО с запасными кандидатами справа | программная компоновка, не измерено по оригиналу |
| Статус и размеры в автоматическом аудите | `draft`, `dimension_status=not_yet_verifiable` | **НЕ подтверждать** по правилу для обычных C |

Нормативная уверенность у двух отметок `1,5` **не приравнивается**
к утверждению всей графики: интерпретация линий размера нуждается в
ручной визуальной сверке. Проверка `check_verified_dimensions`
на новом УГО намеренно не включает правило обычных C.

## Проводящая топология и физическая семантика

- Проводящие примитивы `0..9`: два вывода + два контурных прямоугольника.
  Для примыкания выводов к середине внешней стороны пластин заданы явные
  точки `junctions_mm=[[-2.25,0],[+2.25,0]]`.
- `pin_groups=[["1"],["2"]]`: две **раздельные графические** группы.
  Прямоугольник условной обкладки является проводящей границей своей группы;
  диэлектрический промежуток группу не соединяет.
- Знак `+` — примитивы `10,11`, **не проводящие**. Только графическая
  роль, не физический номер вывода.
- `PartDefinition`: физический/логический pin `1` = `POSITIVE`,
  pin `2` = `NEGATIVE`, оба пассивны;
  `voltage_orientation_rule=positive_not_below_negative`.
  Это соглашение **абстрактного компонента**. Реальные номера выводов
  конкретного изделия нужно сверять с его datasheet.
- Повороты `0/90/180/270` и отражение не меняют физические номера,
  полярность или электрическую принадлежность контактов.

## Воспроизводимые сравнения

После установки проекта из корня репозитория:

```sh
python examples/review_electrolytic_capacitor.py \
  --output-dir output/electrolytic-issue-10
```

Команда генерирует **4 SVG** из штатного `render_symbol_svg`: отдельные
`clean` и `diagnostic` виды для `capacitor.polarized` и
`capacitor.electrolytic`, а также `manifest.json`.
Диагностический слой показывает `body_keepout` и контакты; это не
нормативная размерная графика. Для шрифтов, текста и КОМПАС требуется
отдельная ручная проверка вьюера.

Тесты: `tests/test_electrolytic_capacitor.py`, а также общий структурный
аудит всех 19 DRAFT УГО и колесо доставки. Отрицательные тесты:
лишняя проводящая перемычка; обрыв вывода от обкладки; потеря
проводящего ребра; неправильное `+` у физического pin2; перестановка
полярности; переполюсовка по явно заданным напряжениям; неоднозначное
отсутствие потенциалов; отсутствие ложного нормативного успеха.

## Не реализовано и передача

- **НЕТ** `APPROVED`, формальной подписи ГОСТ/КОМПАС, подтверждения
  8 мм длины и 1,5 мм зазора как обязательных нормативных размеров
  именно электролитического УГО.
- **НЕТ** второго неполяризованного электролитического УГО табл.4 поз.2б:
  это отдельная будущая работа с другим паспортом, а не настройка `+`.
- **НЕТ** симуляции ёмкости, токов, термозависимости, предельного
  рабочего напряжения и реальной распиновки конкретного изделия.
- **НЕ изменены** общие геометрические API, `model/*`, `core/*`,
  `rendering/*`, `catalog/loader.py`. Владелец рендеринга
  отдельно обновляет галерею для 19-го УГО (Issue #17).
- Для ручной приёмки сравнить чёрно-белую SVG-графику с оригиналом
  [Issue #11 review protocol](../standards/issue-11-review-protocol.md)
  по линиям обкладок, расстоянию, знаку `+`, толщине, шрифту,
  охранным зонам и поворотам. Только затем обсуждать отдельный PR,
  меняющий DRAFT на APPROVED.
