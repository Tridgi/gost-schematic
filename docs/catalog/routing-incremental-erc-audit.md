# Incremental routing ERC

The sheet adapter previously ran the full completeness check against a graph containing only the selected net. As a result a real schematic with a second unrouted multi-pin net could not route its first net. Added optional required_nets to the external checker; its default remains the full schematic check. The incremental adapter explicitly requests only the net it is routing. Pin ownership, foreign net shorts, dangling conductors and unknown identities remain global checks. A regression verifies successful incremental routing, rejection of a foreign contact and continued failure of full validation while another net is incomplete. Frozen PR39 sources are unchanged; the current adapter blob is pinned to 3cae90c14eafd313c660429ab127c5e68833db94. Full CI is required before merge.
