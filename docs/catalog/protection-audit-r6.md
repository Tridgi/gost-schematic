# R6 — conservative routing-protection inventory

This report evaluates every installed symbol, using the union of body and authored blue rectangles, not a visual redraw. It records uncovered non-terminal primitive AABBs, blocked outward 1.8 mm escape segments at the project default 550 µm inflation, and constant text annotations requiring measured obstacles. Exact rectangle-union coverage avoids reporting a false gap between touching boxes. AABB overestimation, and the deliberately excluded straight terminal strokes, make this a triage tool rather than proof of routing failure or complete safety. The real sheet adapter additionally reserves primitive bounds; desktop/manual routing is separate. The audit is intentionally non-gating for legacy gaps, while focused tests cover deterministic inventory, union gaps, and selected protected symbols. The workflow puts the actual JSON into the categorized native SVG/PNG artifact. This is not normative approval. All remaining cases must be assessed individually before editing catalog revisions.
