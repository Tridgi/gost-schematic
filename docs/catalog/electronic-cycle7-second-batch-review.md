База: PR #94; исходный каталог из 21 DRAFT не заменяется. **Добавлено 12 новых физических SymbolDefinition/PartDefinition пар**, но **нет утверждённых УГО**. Первые 3 (resistor.variable, resistor.trimmer, fuse.general) сохранены неизменными. Суммарно новая подгруппа: 15 DRAFT; полный каталог: **36 DRAFT** при исходной базе 21.

## Точные первоисточники

[ГОСТ 2.730-73, оригинальные графические таблицы, переиздание май 2002, изм. №1–4](https://www.cad.dp.ua/gost/files/GOST2.730-73.pdf); [официальная карточка Росстандарта](https://protect.gost.ru/gost/details/8e7d0ff4-ab0d-44b5-8efd-b0fcdb13950b). Страницы PDF **1-based**: BJT табл.7 **p.5**, MOS табл.8 **p.6–7**, диоды табл.5 p.3–4, фото табл.9 p.7.

- `transistor.bjt_pnp`: ГОСТ 2.730 **табл.7 поз.1а** — стрелка эмиттера направлена **к базе**; отдельные B/C/E. 
- `transistor.bjt_npn`: **экспериментальное DRAFT-построение** обычного трёхконтактного NPN по базовому обозначению N-эмиттера **табл.1 поз.2** с противоположной PNP стрелкой, **НЕ** недостоверная ссылка на табл.7/1б. Табл.7 **1б явно «NPN с выводом от внутреннего экрана»**, это другой 4-контактный вариант; его самостоятельное УГО BLOCKED.
- `transistor.mosfet_p_enh`: ГОСТ 2.730 **табл.8 поз.3а**; `transistor.mosfet_n_enh`: **табл.8 поз.3б**. Трёхконтактные без вывода от подложки, обогащённого типа, изолированный затвор, **несплошной** канал. P/N стрелки противоположны. Не «JFET», не режим depletion, не body-diode pin.
- Для всех четырёх типов есть отдельные `.with_case` DRAFT варианты: примечания **табл.7/8** допускают рисовать схематическое изображение корпуса. **Circle не SOT/TO-footprint**, не дополнительный вывод. Пока публичный API поддерживает только 1 `symbol_id` у `PartDefinition`, каждый вариант сохранён в отдельной абстрактной символьной/физической паре с одинаковыми **ролями контактов**, не как реальный другой продукт.
- `diode.schottky`: **табл.5 поз.9**, отдельный S-образный катодный признак, отличим от стабилитрона. `diode.led`: **табл.5 поз.10**, две **выходящие** световые стрелки. `diode.photodiode`: **табл.9 поз.2**, две **входящие** стрелки. `diode.varicap`: **табл.5 поз.6**, реальная отдельная ёмкостная обкладка; нельзя соединить её с соседним катодным знаком сплошной внешней токопроводящей линией. A/K — физические, световые стрелки НЕ `GraphicPin`, НЕ `ConductorTopology`.

Размеры штрихов 0.3 мм, корпуса/отступы/стрелки/охранные области/длины 10–11 мм — **EDITORIAL / ПРОЕКТНЫЕ**. ГОСТ 2.730 п.15, справочное приложение 2 даёт относительную *модульную* геометрию, **не обязательные метры/миллиметры**. 1:1 исходный векторный КОМПАС/табличный overlay и подпись эксперта отсутствуют. Точные vendor pin numbers 1/2/3: **условная нумерация каталога**, не датащит прибора.

## Доказательство сохранения электрофизики

Для каждого нового UGO: отдельно `src/gost_schematic/catalog/symbols/` и `parts/`, реальные `GraphicPin` в точных координатах µm и парные `PhysicalPin` по номерам; BJT `B,C,E`, MOS `G,D,S`, диоды `A,K`; по одному conducting-ink island на каждый вывод, никаких неоговорённых электрических Junction. `Circuit.Net` строится только по явным `PinRef`, не по окружности корпуса/стрелке/декоративной линии. Все 8 D4-трансформаций без подмены pin ID/типа и с явно сохранённой физической стрелкой; отрицательные тесты на фальшивую связь B/C, G/D, A/K, на оптический фантомный pin, на изменение физической роли и загрязнение графики.

## Единая настоящая галерея

`python -m examples.review_electronic_cycle7_extended --output-dir output/cycle7-all-catalogue` строит **одну 5×3 галерею всех 15 новых УГО** в чистом/диагностическом SVG 275×180мм; отдельный манифест содержит SHA256 исходников + всех `PinRef` ролей/координат. Растеризация **300 DPI** проверяется по фактической физической шкале SVG и SHA. `font-family=OpenGost Type A` устанавливается только на CI runner из подтверждённого лицензионного внешнего источника, **файлы шрифта не коммитятся**. Приёмка сравнивает визуальную сцепку реальных `SymbolDefinition` с `PartDefinition`; эта SVG-галерея не является подписанным ГОСТ-эталоном.

## Оставшиеся BLOCKED

В `electronic-cycle7-second-batch-cards.json` перечислены 17+ конкретных кандидатов и их реальные причины: **двусторонний стабилитрон** ГОСТ 2.730 табл.5/4б требует особой двусторонней семантики (A/K всей системы неоднозначны); туннельный/обращённый диод, JFET N/P, depleted MOS P/N, MOS с отдельной подложкой, NPN с экраном, составной BJT, тиристор/симистор/оптопара, специализированные FU, реальные XP/XS по ГОСТ 2.755-87. **XP/XS — физические части разъёма с производственной нумерацией**, Issue #90 именованные продолжения линий = **не** `PartDefinition`. Для каждого дальнейшего вида — сначала точная фигура и физический контракт, затем отдельный DRAFT и независимая визуальная экспертиза. Никаких фальшивых УГО ради счётчика.

**Источник требований ESKD:** нормативная база Issue #27 и независимые 107 предварительных карточек ESKD Draft PR #95; `SOURCE_FIGURE_INSPECTED` означает лишь найденную форму, но НЕ `APPROVED` и НЕ 1:1 размерную проверку.
