# Issue #11 — протокол воспроизводимой ручной сверки УГО (ГОСТ ↔ SVG ↔ КОМПАС)

**Назначение:** независимая проверка электролитического конденсатора и каждого из 15 УГО катушек/дросселей; результат передаётся **координатору** и **чату каталога**. Документ — план испытаний и шаблон доказательств, **не акт принятия**. Все существующие УГО сохраняют статус **DRAFT**.

## 1. Контроль источника и версии

На каждую проверяемую форму заполнить:

| Поле | Требуемое значение |
|---|---|
| `symbol_id` / `revision` | Точный ID и редакция каталога |
| `source_sha256` | SHA-256 именно проверяемого JSON и эталонного экспортированного файла |
| `standard` | Обозначение, год, применимые изменения, дата документа, юрисдикция |
| `official_status_url` | Карточка действительности в Росстандарте |
| `figure_url` | PDF и **лист**, таблица, **номер позиции / подпункт (а, б)**, форма I/II |
| `reference_format` | Официальная/контролируемая печатная копия, SVG/Вектор КОМПАС, либо публичное PDF-воспроизведение |
| `evidence_level` | `direct_example`, `composition`, `adaptation`, `unverified` |
| `reviewer` / `review_date` | Человек и дата фактического сравнения, **не автор кода по умолчанию** |
| `verdict` | `PASS_MANUAL`, `REJECT`, `BLOCKED`; при нехватке источника = `BLOCKED` |

Источники: [ГОСТ 2.728-74 — официальный статус](https://protect.gost.ru/gost/details/ba115ccd-e5aa-4ba1-a672-b17170f1a7f2), [рисунки табл. 4–6](https://helpeng.ru/public/normdoc/eskd/gost_2.728-74.pdf); [ГОСТ 2.723-68 — официальный статус](https://protect.gost.ru/gost/details/69e5c69a-bbb9-4a6a-a8d1-2cf54c2a2164), [рисунки табл. 1–2](https://helpeng.ru/public/normdoc/eskd/gost_2.723-68.pdf). На 2026-11-12 оба документа значатся действующими в РФ; сканы — **неофициальные воспроизведения графики**, статус подтверждает портал, а не домен PDF.

## 2. Подготовка оригиналов и детерминированных образцов

1. Взять **один согласованный commit SHA**, выгрузить исходные JSON, отчёт каталога и чистые SVG в физическом масштабе **1:1 в миллиметрах**. Фиксировать версии рендера, ПО, исходной страницы ГОСТ и библиотечного элемента КОМПАС. Не округлять микрометры для вида и не масштабировать отдельные УГО ради визуального совпадения.
2. Из КОМПАС получить **разрешённый** векторный эталон соответствующей **формы II**, с учётом материала сердечника и числа контактов. Документировать тип, редакцию и происхождение библиотеки. Если доступен только растр/скан, отметить, что он пригоден для сравнения формы, но **недостаточен для автоматической сертификации численных размеров**.
3. Для каждого UGO сформировать: чистый SVG, SVG с измерительными линиями/контактами, файл с описанием полученных номинальных размеров, графический overlay эталона и результата; сохранять SVG как вектор, а не PNG, при котором метрика штриха меняется.
4. Сначала сравнить семантику и отдельные рисунки стандарта; **затем** — масштаб, толщину линии, соединения, шрифты и листовое размещение. Повороты 90/180/270° и зеркала проводить **отдельно**, проверяя, что маркировка и реальные контакты остаются правильными.
5. Результат каждого шага записывать как `PASS` / `FAIL` / `BLOCKED` с прямой ссылкой на первоисточник и приложенный файл; не превращать отсутствие эталона в `PASS`.

## 3. Покомпонентные критерии

| Проверка | Что сравнить / критерий отказа |
|---|---|
| **E1: электролитическая форма** | Обычный `capacitor.polarized` (табл. 4, поз. 1, прим.) **не тождественен** электролитическому (табл. 4, поз. 2а). Сверить форму двух графических обкладок; для 2б — соответствующий неполяризованный вариант |
| **E2: размерная трассировка** | Для обычного конденсатора — п.7 табл.6 поз.9, **8 мм / 1,5 мм**. Для электролитического — **поз.10** с собственными отметками `1,5` мм; не переносить полный размерный профиль поз.9 без источника. Указать, какой размер чему соответствует на эталоне |
| **E3: полярность** | Графический `+` соотнести с реальным положительным контактом. Допустимость опускания `+` по примечанию к табл.4 поз.2 — **условная**; без оценки неоднозначности скрывать нельзя. Проверить зеркала, направления выводов, обход текста |
| **I1: витки / выводы** | Форма II табл.1 поз.1 и табл.2 поз.1: полуокружности одной последовательной обмотки, без внутреннего разрыва и ошибочного мостика. **Число полуокружностей нормативно не фиксировано** |
| **I2: отводы** | Табл.2 поз.3: контакт присоединён к намеченной дуге, не касается случайного соседнего витка. `double_tapped` требует отдельной аргументации двух одновременно существующих отводов |
| **I3: скользящий контакт** | Табл.2 поз.4: подвижный контакт графически отличим от фиксированного отвода; касание и направление наконечника понятны, нет лишней физической связи. Одноконтактная форма проверяется как адаптация |
| **I4: сердечник** | Табл.1 поз.2а/2б/2в: тип штриха, разрыв, ферритовая **толстая линия**, магнитодиэлектрический **штриховой рисунок**, положение относительно обмотки; коэффициент 2× и шаг штрихов 2,0/1,1 мм **проектные** |
| **I5: регулировка / Cu** | Табл.2 поз.6–7: графическая разница подстройки сердечником и переменного элемента; символ **Cu**, его положение и линия немагнитного сердечника. Проверить, что штриховая реализация `nonmagnetic_copper` не противоречит исходному **сплошному** примеру табл.1 поз.2а |
| **I6: дроссели** | Табл.2 поз.1 и 8: отличать двухконтактный дроссель без сердечника от ферромагнитного; `choke.ferrite` — композиция, а не отдельное доказанное изображение табл.2 |
| **T1: электрическая графика** | `ConductorTopology`: до/после преобразования все нарисованные проводящие штрихи имеют нужные `junctions`, контакты не висят; `Cu`, сердечник, `+` и указатель регулировки **не** образуют дополнительный `Net` |
| **T2: системная графика** | Параллельные связи, размещение надписей, фактический зазор между штрихами, реальные метрики чертёжного шрифта; отсутствие AABB-пересечения **не** является доказательством нормативных расстояний |

**Негативные образцы:** намеренно перепутанный электролитический плюс; слитые обкладки; оторванный TAP/SLIDER; неверно объединённые пересекающиеся графические линии; стрелка со случайным проводящим контактом; неверный сердечник (феррит ↔ магнитодиэлектрик); отсутствие `Cu`; неверная редакция нормативного профиля; масштабированная только картинка без подписанных размеров. Они должны выдавать ошибку/запрет принятия или `BLOCKED`, а не тихий `PASS`.

## 4. Шрифт, знак «+», номиналы, линии

- [ГОСТ 2.304-81](https://protect.gost.ru/gost/details/2acb3258-c28c-4e4a-b7ac-208043f2d95e), **п. 2.1, табл. 1**: для **типа А** `d=h/14` (высота прописной `h`); допускается без наклона и с наклоном около 75°. Проверять **реальный контур** знаков `+`, `Cu` и буквенно-цифровых обозначений, межсимвольные интервалы, выбранную высоту, интерлиньяж, толщину и знак наклона. Загрузка OpenGOST TTF и совпадение имени гарнитуры **не доказывают** соответствие глифов.
- [ГОСТ Р 2.304-2026](https://protect.gost.ru/gost/details/f744cc7d-56c7-4930-98c0-afeedd135827) имеет статус **«Принят»**, дата введения **01.10.2027**, с правом досрочного применения. Это **не** автоматическая замена профиля 2.304-81 при документе 2026-11-12. При досрочном выборе нужны реальные нормы нового текста, который не включён в проверку.
- [ГОСТ 2.728-74, п.7](https://helpeng.ru/public/normdoc/eskd/gost_2.728-74.pdf#page=9): толщина линии графики конденсатора/резистора соответствует толщине линий электрической связи. Катушкам проверять согласованность с листовыми правилами; специальные толстые сердечники **не выравнивать обратно** до ширины проводников.
- Для листовых расстояний и линий использовать действующие ссылки [реестра](registry.md) на **ГОСТ 2.701-2008, пп. 5.3.4, 5.4.2–5.4.4, 5.5.1–5.5.2**: не путать просвет по реальной краске с расстоянием между осевыми линиями; с нормативными **1/2/3 мм** обращаться как с листовыми условиями, а не произвольными паддингами локального хитбокса.

## 5. Шаблон карточки вердикта

Для **каждого** UGO должна быть отдельная карточка с заполненными полями:

| Ключ | Значение (заполняет ревьюер) |
|---|---|
| `symbol_id`, `revision`, `commit_sha` | — |
| `official_card`, `pdf_edition`, `table_item`, `form` | — |
| `gost_original_file`, `kompas_reference`, `reference_sha256` | — |
| `svg_clean`, `svg_overlay`, `geometry_sha256` | — |
| `dimensions_evidence` (каждое число ↔ конкретная размерная линия) | — |
| `polarity_and_contacts`, `core_style`, `font_profile`, `stroke_profile` | — |
| `rotations_and_mirrors`, `negative_cases`, `topology_audit` | — |
| `differences`, `open_questions`, `reviewer`, `review_date` | — |
| `verdict` и `approval_issue_or_pr` | **BLOCKED** до физического сравнения и отдельного одобрения |

Точность внутренней модели **0,001 мм** — разрешение хранения, **не допустимый нормативный допуск** при сравнении SVG с ГОСТ/КОМПАС. Для неразмеренных штрихов фиксировать *характер/относительные пропорции*; допуск можно установить **только** явно согласованным процессом ручной приёмки, не выдавая его за текст ГОСТ.
