# Журнал проекта — GOST Schematic Engine

Этот файл ведётся по этапам разработки. Каждая запись привязана к ветке/PR и контрольной проверке CI. **Зелёные тесты означают работоспособность автоматических проверок, но не подтверждают соответствие ГОСТ.**

## 2026-11-12 — Этап 0.12: техническое завершение и нормативная трассируемость

- **PR:** [#9 — normative topology](https://github.com/Tridgi/gost-schematic/pull/9), ветка `feature/stage0-12-normative-topology`, база PR #8. Статус: **DRAFT**, без слияния в `main`.
- **План до изменений:** [docs/plans/stage-0.12-normative-topology.md](plans/stage-0.12-normative-topology.md).
- **Источники:** действующие и будущие нормативы, даты, официальные URL и краткие технические интерпретации в [реестре](standards/registry.md). Сопоставлена графика исходных таблиц ГОСТ 2.723-68 и ГОСТ 2.728-74; [матрица приёмки 18 УГО](standards/ugo-review-matrix.md) сохраняет неопределённости.
- **Новая модель:** `ConductorTopology` отделяет явные проводящие штрихи УГО от физических контактов и внешнего `Circuit.nets`. Обмотки и отводы проверяются точно, обкладки и выводы резистора не объединяются ошибочно. Точки соединения задаются явно; пересечение линий без узла само сеть не создаёт.
- **Нормативный профиль:** `standards/requirements_2026_ru.json` с 4 будущими редакциями и правилами геометрии. Реализован выбор версии по **дате документа**, с явным досрочным применением.
- **Численные проверки:** фиксированный резистор 10×4 мм, длина обкладок двух вариантов конденсатора 8 мм и зазор 1,5 мм; толщина линий связи 0,2–1,0 мм, зазор ≥3 мм между параллельными линиями **по краям штрихов**.
- **Исправлены обнаруженные дефекты:** неaligned обкладки и несвязанные обкладки больше не проходят проверку только по длине/зазору; совпадающие фрагменты одного net не признаются «двумя соседними линиями»; конфликтные или неразмеченные совпадающие фрагменты считаются ошибкой; длинная цепочка топологического графа проверяется без рекурсивного переполнения.
- **Сборка:** аудит каталога и проверка содержимого собранного отдельного wheel теперь выполняются **на Python 3.12 и 3.13**, а не только на одной версии. Из wheel проверяются 3 УГО JSON, 3 физические детали, 15 вариантов катушек и машиночитаемый стандарт.
- **Проверка кода:** [GitHub Actions #43289319096](https://github.com/Tridgi/gost-schematic/actions/runs/43289319096) — **364/364 тестов** на каждой версии Python, **Ruff чисто**, **18/18 UGO прошли структурный аудит**, **18/18 DRAFT**, **0 блокирующих ошибок**, wheel payload OK на обеих версиях. Всего **+61 тест** относительно этапа 0.11 (303 → 364).
- **Документы ограничений:** [известные ограничения](standards/known-limitations.md), [система топологических уровней](standards/topology.md). **Только 3 УГО покрыты точными проверками части размеров; 15 УГО без нормативно подтверждённых размеров.** Ни один элемент не утверждён по ГОСТ.
- **Заключение:** этап 0.12 технически завершён по заявленным ограниченным критериям; полная сертификация ГОСТ, точная визуальная сверка с КОМПАС и внешняя трассировка НЕ входят в подтверждённый результат. После финального повторного CI ветка остаётся зафиксированной до следующего задания.

## 2026-11-12 — Этап 0.11: проверено автоматикой, ожидает утверждения

- **PR:** [#8 — structural quality audit](https://github.com/Tridgi/gost-schematic/pull/8), поверх PR #7. Данные остаются DRAFT.
- **Исправлено:** внешние выводы больше не могут молча «висеть» или продолжаться наружу от УГО — добавлены ошибки `PIN_GRAPHIC_DISCONNECTED` и `PIN_LEAD_NOT_INWARD`. Проверка строит индекс концов линий за линейное время.
- **Исправлено:** у подвижного отвода катушки стержень доведён до вершины указателя на обмотке; отдельный регрессионный тест проверяет соприкосновение всех трёх линий.
- **Исправлено:** `stroked_bounds` учитывает толщину каждого штриха и используется для визуальных габаритов, границ и предотвращения накладок; старое `bounds` сохранено для совместимости.
- **Добавлено:** физический паспорт `resistor.fixed` с двумя неполярными выводами.
- **Аудит:** `scripts/audit_symbol_catalog.py` проверяет все 18 УГО и физические паспорта, выдаёт детерминированный JSON с исходными SHA-256.
- **Подтверждённый CI:** [GitHub Actions #43276772190](https://github.com/Tridgi/gost-schematic/actions/runs/43276772190). **Python 3.12: 303/303**, **Python 3.13: 303/303**, **Ruff: чисто**; аудит: **18 УГО, 18 draft, 0 ошибок**. Артефакт `draft-catalog-integrity-audit`.
- **Разница с исходным этапом:** +17 автоматических тестов (286 → 303).
- **Что не доказано:** соответствие ГОСТ по оригиналам КОМПАС, электрическая связность всех внутренних графических линий, полная трассировка, учёт ЭМС/режимов работы, сертификация шрифта.
- **Статус:** технический этап 0.11 готов к ручному просмотру; изменения не объединялись в `main`.
- **Решение:** [ADR-0009](decisions/0009-pin-attachment-and-stroked-extents.md), [quality gates](quality-gates.md).
