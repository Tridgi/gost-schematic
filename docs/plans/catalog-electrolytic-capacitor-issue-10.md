## 1. Исходные факты

- `capacitor.fixed` — две отдельные линии пластин, два неполярных физических контакта, два графически изолированных проводящих острова.
- `capacitor.polarized` — **общий** поляризованный конденсатор, отдельные линии пластин (8 мм, просвет 1,5 мм для данного шаблона), указатель «+» у графического вывода 1, а отдельный физический паспорт задаёт pin 1 = positive и pin 2 = negative. Номинальная ёмкость задаётся `QuantityKind.CAPACITANCE`, а не графической надписью.
- ГОСТ 2.728-74, действующий по [Росстандарту](https://protect.gost.ru/gost/details/ba115ccd-e5aa-4ba1-a672-b17170f1a7f2), [издание 2002 с изм. №1,2](https://helpeng.ru/public/normdoc/eskd/gost_2.728-74.pdf), **таблица 4, п. 2а/2б (PDF стр. 7)** выделяет электролитические *поляризованный* и *неполяризованный*; **таблица 6, п. 10 (PDF стр. 10)** показывает самостоятельный размерный вариант. Это не графическое УГО позиции 1 со знаком плюс.
- На рисунке п. 10 отмечены два размера **1,5**, но назначение именно этим пластинам/зазору, высота, толщина, заливка и позиционирование относительно оси требуют нормативной векторной расшифровки. Числа **8 мм и 1,5 мм для обычного C** не переносятся автоматически на специальный электролитический вид.
- Плюс для электролитического поляризованного допускается опустить **только если это не вызовет неоднозначности** (примечание к табл. 4), но на первом ревью-варианте будем рисовать явно. Графический «+» не задаёт физическую полярность, а только согласуется с `PhysicalPin.polarity`.

## 2. Границы и модель

**Предлагаемое имя** для первого, поляризованного вида:
- Графический ID: `capacitor.electrolytic` (revision 1, status `draft`).
- Физический part ID: `capacitor.electrolytic`, `symbol_id` тот же, `reference_prefix`: `C`, `nominal_kind`: `capacitance`, `voltage_orientation_rule`: `positive_not_below_negative`.
- Физические выводы: pin `1` positive, `2` negative, оба `passive` — это **внутреннее соглашение модели**, не маркировка всех производимых изделий. Реальная распиновка корпуса/номера должны происходить из паспортов производителя; нельзя путать их с анодом/катодом абстрактного УГО.
- Графические выводы должны иметь постоянные номера `1`/`2`, внешние координаты и стороны, а `+` быть расположен со стороны `1`. `mirror_x` и поворот не меняют физическую полярность.
- `conductor_topology`: **две раздельные группы `[["1"], ["2"]]`** и только проводящие штрихи обкладок/выводов; знак `+` и любая непроводящая обводка не входят в граф электрической краски.
- Отдельные слоты `refdes`/`value` и защитные зоны текста; stroke-aware габариты; стабильные коридоры доступа к пинам.
- Электролитический **неполяризованный** вариант из табл. 4 п. 2б — **НЕ** тот же физический паспорт с пустым знаком. Для него понадобится отдельное исполнение `capacitor.electrolytic_nonpolar` (имя согласовать с координатором при следующем задании), оба `TerminalPolarity.NONE`, `VoltageOrientationRule.NONE`. В Issue #10 первична только поляризованная модель.

## 5. Позитивные и негативные тестовые критерии

| Проверка | Ожидаемое поведение |
|---|---|
| Отдельный ID | `electrolytic != polarized != fixed`; `revision=1`, `status=draft`, источник точный, не общий «ГОСТ compliant» |
| Паспорт выводов | `PartDefinition` с точно двумя passive pin `1` POSITIVE и `2` NEGATIVE; название класса не меняет реальные pin IDs |
| Согласование графики/семантики | Обозначение `+` привязано к pin 1, а не выбранной стороне экрана; взаимно переставленные плюсы/минусы дают `GRAPHIC_POLARITY_MISMATCH` |
| Топология | pin groups `(("1",),("2",))`, нет `TOPOLOGY_UNEXPECTED_BRIDGE`, плюс исключён из проводящих линий |
| Негативный short | Добавление проводящей перемычки между обкладками вызывает блокирующую ошибку, не «корректную схему» |
| Негативный обрыв | Сдвиг/разрыв вывода от обкладки обнаруживается как нарушенная связность или отсутствующий узел |
| Размеры | Длина/толщина/просвет из **подтверждённых** чисел с `1 µm` точностью; +/−1 µm или переставленная обкладка не проходят targeted regression |
| Повороты и отражение | Для `0/90/180/270°` × `mirror_x` номера и физическая полярность не меняются, внешний pin-escape сохраняется |
| Подписи | `refdes`, `value` не пересекаются с нанесёнными электродами/коридорами; `470 µF` форматируется отдельно от текста графики |
| ERC | Обратная полярность выдает ERROR при известном общем reference; неизвестные напряжения выдают WARNING, имена сетей не угадываются |
| Независимость | Существующие `fixed` и `polarized` не меняют геометрию, SHA или семантику |
| Каталог | Аудит проходит без ошибок, возвращает статус DRAFT для всех; стандартизированные размеры считаются подтверждёнными **только при отдельном rule из #11**, не из базового п. 9 |
| Wheel | Новый JSON УГО + part присутствуют в wheel; CI 3.12/3.13 и Ruff проходят |
